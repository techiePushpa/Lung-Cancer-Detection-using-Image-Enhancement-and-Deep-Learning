# Lung Cancer Detection using Image Enhancement and Deep Learning

An AI-powered medical imaging project that detects lung cancer from **CT scan or Chest X-ray images** using **Image Enhancement** techniques and **Convolutional Neural Networks (CNNs)**. The system improves image quality before classification, enabling more accurate and reliable detection to support early diagnosis and assist healthcare professionals.

## 🚀 Features

* Image preprocessing and enhancement for improved feature visibility.
* CNN-based deep learning model for **Cancer / Non-Cancer** classification.
* Data augmentation to improve model robustness and reduce overfitting.
* Performance evaluation using **Accuracy, Precision, Recall, F1-Score,** and **ROC-AUC**.
* Modular and scalable pipeline for training, testing, and inference.

## 🛠 Tech Stack

* **Language:** Python
* **Libraries:** OpenCV, NumPy, Pandas, Matplotlib
* **Deep Learning:** TensorFlow/Keras *(or PyTorch)*
* **Model:** Convolutional Neural Network (CNN)

## 📊 Project Workflow

Image Dataset → Image Enhancement → Data Augmentation → CNN Model Training → Prediction → Performance Evaluation

## 🎯 Objective

To develop a reliable deep learning-based system for **early lung cancer detection** by combining image enhancement techniques with CNNs, improving diagnostic accuracy and supporting AI-assisted medical screening.
